# Frontend

Aplicacion web de RedVital construida con React y TypeScript.

La carpeta `src/modules/` refleja los modulos funcionales del SRS. Los
componentes reutilizables entre modulos viven en `src/shared/`.

## Ejecutar en local

```bash
npm install
npm run dev
```

La aplicacion queda disponible en http://localhost:5173 y espera el backend en
http://localhost:8080.
